# Project Overview

## Produto

PedeOutra é um micro SaaS B2B de recompra. Um pequeno distribuidor cria um
catálogo simples, compartilha um link com clientes comerciais e recebe pedidos
recorrentes. O comprador usa o celular sem conta; o fornecedor confirma o pedido
no painel.

## ICP inicial

Microdistribuidores com 5 a 150 clientes recorrentes que hoje recebem pedidos
por WhatsApp, sobretudo embalagens, limpeza, água, gelo, descartáveis e
reposição de insumos.

## Proposta de valor verificável

- Reduzir o tempo de redigir pedidos manualmente.
- Evitar erro de item/quantidade com catálogo e snapshots.
- Centralizar um histórico básico por fornecedor e cliente.
- Repetir um pedido anterior em poucos toques.

Não há promessa de aumento de faturamento, depoimento inventado ou garantia de
venda. Pedido é solicitação comercial sujeita a confirmação do fornecedor.

## Fluxos

### Fornecedor

Landing → teste de 7 dias sem cartão → conta → organização → produtos →
catálogo → pedidos → confirmação → link de recompra → assinatura.

### Comprador B2B

Catálogo público → quantidades → identificação mínima → envio → confirmação
de "pedido enviado para análise". Em compras seguintes, link opaco de recompra
recria a sugestão anterior sem expor dados pessoais.

## Modelo comercial

- Um plano: R$ 29,90/mês.
- 7 dias de teste sem cartão.
- Assinatura do fornecedor via Asaas Checkout recorrente em cartão.
- O PedeOutra não cobra os pedidos B2B e não intermedeia pagamento entre as partes.

## Não é

ERP, CRM amplo, PDV, delivery, marketplace, logística, emissor fiscal, bot de
WhatsApp, IA generativa ou gateway de pagamento dos pedidos.

## Métrica de validação

Visita → cadastro qualificado → 5 produtos → link compartilhado → primeiro
pedido → primeira recompra → checkout → pagamento → renovação. As metas são
hipóteses de aprendizado, não previsões.
